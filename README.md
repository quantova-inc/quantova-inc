## 🔭 What We're Building

| Project | Description |
| :------ | :---------- |
| **Quantova Virtual Machine (QVM)** | The core execution environment of the Quantova protocol. |
| **Post-Quantum Signatures** | Lattice-based signatures (ML-DSA / Dilithium-family) for accounts and validators. |
| **Quantova SDK** | Tooling for developers to build and deploy on the network. |
| **Q-Mask** | Quantum-safe wallet — browser extension and mobile app. |
| **Quantova Tools** | Node operator and developer utilities. |
